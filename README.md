# 🌐 Networking Labs – Cisco Packet Tracer

This repository contains hands-on networking labs built using **Cisco Packet Tracer**, focusing on real-world network design, routing protocols and configuration practices.

---

## 📌 Overview

The goal of this repository is to strengthen practical networking skills by implementing different network topologies and protocols through simulation.

Each project demonstrates how networks function in real environments, along with proper configuration and testing.

---

## ⚙️ What Each Lab Includes

Each folder contains:

* 📄 `.pkt` file (Cisco Packet Tracer project)
* 🖼️ Network topology diagram
* 📝 Configuration commands
* ✅ Testing and output verification

---

## 🛠️ Tools Used

* Cisco Packet Tracer
* CLI Configuration
* Networking Concepts

---

## 📖 How to Use

1. Download the `.pkt` file
2. Open it in Cisco Packet Tracer
3. Analyze the topology and configurations
4. Run simulations and test connectivity

---

## 🎯 Learning Outcome

* Understand how routing protocols work in real networks
* Gain hands-on experience with network configuration
* Improve troubleshooting and design skills
